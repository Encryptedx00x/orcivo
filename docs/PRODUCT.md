# Orcivo — Documento de Produto

> Esboço inicial — detalhar durante a Fase 1

## O produto

SaaS B2B para técnicos instaladores brasileiros organizarem clientes, orçamentos, OS e recebimentos — no celular em campo e no computador no escritório.

## ICP (Ideal Customer Profile)

Técnico autônomo / MEI / microempresa com até 3 técnicos. Hoje usa WhatsApp + Excel + Word. Faz portões, câmeras, alarmes, cerca elétrica, energia solar ou automação residencial.

## Core Value

Um técnico consegue criar um orçamento profissional com a identidade visual da própria empresa, compartilhar via WhatsApp, receber aprovação do cliente e ter a OS gerada automaticamente — tudo pelo celular.
