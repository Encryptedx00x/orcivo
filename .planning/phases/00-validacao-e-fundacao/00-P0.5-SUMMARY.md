## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Converted next.config.ts to next.config.mjs**
- **Found during:** T03
- **Issue:** Next.js 14.2 does not support `next.config.ts` — throws "Configuring Next.js via 'next.config.ts' is not supported"
- **Fix:** Deleted `next.config.ts`, created `next.config.mjs` with identical config using JSDoc type annotation
- **Files modified:** apps/web/next.config.mjs (created), apps/web/next.config.ts (deleted)
- **Commit:** 7ad2cfa

**2. [Rule 2 - Missing config] Added .eslintrc.json for Next.js ESLint**
- **Found during:** T03
- **Issue:** Next.js build failed with "Parsing error: The keyword 'import' is reserved" due to missing ESLint config for App Router
- **Fix:** Added apps/web/.eslintrc.json extending "next/core-web-vitals"
- **Files modified:** apps/web/.eslintrc.json
- **Commit:** 7ad2cfa

### Known Platform Limitation (not a bug)

**Windows pnpm symlinks with `output: 'standalone'`:** The `next build` step completes compilation successfully (`✓ Compiled successfully`) but the final standalone copy step fails with EPERM on symlink creation. This is a Windows filesystem limitation with pnpm's symlink strategy. The Docker build on Linux (VPS) is not affected — Docker uses a Linux filesystem where symlinks work normally. No action required.

## Human Actions Required (Post-Plan)

### 1. Deploy na VPS
Follow `docs/runbooks/deploy.md`:
```bash
# Na VPS
cd /opt/orcivo
git clone https://github.com/Encryptedx00x/orcivo.git .
cd infra
docker compose up -d --build backend web
curl https://api.seudominio.com.br/health
```

### 2. EAS Build — APK para Android
```bash
cd apps/mobile
npx eas-cli build --platform android --profile preview
# Instalar o APK gerado em Android real
```
Pré-requisito: criar conta em expo.dev, rodar `eas login`, substituir `REPLACE_WITH_EAS_PROJECT_ID` em app.json.
