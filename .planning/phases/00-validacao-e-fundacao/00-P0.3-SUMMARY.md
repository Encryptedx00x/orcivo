# Phase 0 Plan P0.3: Docker Compose Stack Summary

**One-liner:** PostgreSQL 16 + Redis 7 + MinIO + Caddy 2 stack via Docker Compose with bind-mount volumes on /mnt/data, automatic HTTPS via Let's Encrypt, and daily pg_dumpall backup with 7-day retention.

## What Was Built

Five infrastructure files ready to copy to the VPS and run:

| File | Purpose |
|---|---|
| `infra/docker-compose.yml` | Four-service stack: postgres, redis, minio, caddy |
| `infra/Caddyfile` | Reverse proxy with auto-HTTPS for api, app, storage, s3, www |
| `infra/.env.example` | Environment variable template (no real secrets) |
| `infra/scripts/backup-volumes.sh` | Cron-ready backup with pg_dumpall and 7-day retention |
| `docs/runbooks/stack-setup.md` | Step-by-step deploy guide covering STACK-01..09 |

## Next Step for User

1. Buy the domain (any registrar)
2. Follow `docs/runbooks/stack-setup.md` to deploy the stack on the VPS:
   - Configure DNS (7 A records pointing to VPS IP)
   - Copy files to `/opt/orcivo/infra/`
   - Create `.env` with real credentials (save to Bitwarden first)
   - `docker compose up -d` and verify with checklist

The actual stack execution on the VPS is a human step — the config files are complete and ready.
