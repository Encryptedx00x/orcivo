Criar `docs/validation/demo/index.html` — um HTML estático click-through que simula o fluxo principal do Orcivo para uso em entrevistas.

**Regras absolutas (per D-01, D-02, D-03):**
- Zero JavaScript de framework (sem React, Vue, etc.)
- Zero backend, zero fetch para API real
- Navegação entre "telas" via `<a href>` ou onclick simples que mostra/oculta divs
- Usar a paleta oficial: primary `#6D28D9` (nunca `#2563EB`), fundo `#FFFFFF`, tinta `#0A0A0F`
- Fonte: Inter (Google Fonts CDN)
- Ícones: pode usar SVG inline simples (sem biblioteca externa neste demo)
- Idioma: pt-BR em todos os textos
- Plano referenciado: "Orcivo Mais" (nunca PRO, FREE, TOP)

**Fluxo a demonstrar (7 telas em sequência):**

1. **Tela: Lista de Clientes** — cabeçalho "Orcivo", lista com 3 clientes fictícios (nome, endereço, último contato), botão "+ Novo cliente"
2. **Tela: Criar Orçamento** — formulário com campos: cliente (selecionado), descrição do serviço, itens (2 linhas pré-preenchidas: "Portão deslizante + motor" R$850 e "Instalação" R$200), total R$1.050,00
3. **Tela: Preview do PDF** — simulação de PDF do orçamento com logo "Empresa do Técnico", dados do cliente, itens, total, validade 7 dias, botão "Enviar via WhatsApp"
4. **Tela: Aguardando Aprovação** — status "Enviado — aguardando aprovação" com ícone de relógio, data de envio
5. **Tela: OS Gerada** — "Orçamento aprovado! Ordem de Serviço #001 criada automaticamente", dados da OS, status "Agendada"
6. **Tela: Agenda** — calendário simples (semana atual), OS #001 aparece no dia seguinte como evento
7. **Tela: Financeiro** — lista de recebimentos: "OS #001 — R$1.050,00 — Pendente", saldo do mês

**Estrutura HTML:**
- Um único arquivo `index.html` auto-contido
- Navegação por JavaScript vanilla: `document.querySelectorAll('.screen')` com `display:none/block`
- Botão "← Voltar" em cada tela exceto a primeira
- Barra de progresso simples no topo: "Tela X de 7"
- Texto discreto no rodapé: "Demo para entrevista — não representa o produto final"

**Dados fictícios a usar:**
- Cliente: "João da Silva — Rua das Flores, 123 — São Paulo/SP"
- Empresa do técnico: "Portões & Câmeras Ltda — CNPJ 12.345.678/0001-90"
- Datas: usar datas relativas a 2026-05
