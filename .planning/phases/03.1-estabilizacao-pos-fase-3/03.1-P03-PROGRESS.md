## P03-T01 — inventário (DONE)

### StorageService (`src/storage/storage.service.ts`)

- Buckets: `orcivo-pdfs`, `orcivo-photos` (constantes).
- `onModuleInit`: cria bucket **e aplica policy PÚBLICA** (`Principal: '*'`,
  `s3:GetObject`) — **só na criação**; buckets já existentes mantêm a policy
  antiga.
- `uploadBuffer(bucket, objectName, buffer, contentType)` → retorna
  **`${MINIO_PUBLIC_URL}/${bucket}/${objectName}`** (URL pública permanente).
- `deleteObject(bucket, objectName)`.
- Sem `presignedGetObject`, sem verificação de magic bytes.

- `quote_approvals.signature_image_url` — embutido no PDF regenerado via
  `<Image src={signature_image_url}>` (`quote-pdf.service.tsx:366`) — precisa ser
  resolvível no momento da geração.
- `work-order-photo.service.deletePhoto` — deriva o objectName de
  `file_url.split('/orcivo-photos/')[1]`.

### Schema

`quote.pdf_url String?`, `quote_approvals.signature_image_url String?`,
`work_order_photos.file_url String` — hoje guardam URL pública completa.

### Validação de upload existente

- Foto: MIME allowlist (`image/jpeg|png|webp`) + tamanho ≤ 10MB. **Sem magic
  bytes**, sem checagem de vazio, sem limite de quantidade.
- Assinatura: sem validação (base64 → buffer direto).

### Env

`MINIO_ENDPOINT/PORT/USE_SSL/ACCESS_KEY/SECRET_KEY/PUBLIC_URL` + `MINIO_BUCKET`
(test). Dev: `localhost:9000`, `minioadmin/minioadmin`.

## P03-T02 — decisão técnica (DONE)

**Decisão: persistir OBJECT KEY, resolver signed URL sob demanda na leitura.**

- As colunas `pdf_url` / `file_url` / `signature_image_url` passam a guardar o
  **object key** (`{company}/quotes/{id}.pdf`), não a URL pública. Bucket é
  constante por tipo de artefato (PDF → `orcivo-pdfs`, foto/assinatura →
  `orcivo-photos`), então não precisa guardar o bucket.
- **Sem migration de schema** — as colunas continuam `String`. Linhas legadas
  guardam URL completa; `StorageService.resolveKey(stored)` aceita as duas formas
  (URL completa legada → extrai a key; senão → key crua). Compat sem tocar dados.
- Alternativa "normalizar URL existente" descartada: exigiria reescrever linhas
  (T10 destrutivo) e não elimina a dependência de URL pública.

Registrar como nota no plano (não é ADR — é escolha interna reversível).
