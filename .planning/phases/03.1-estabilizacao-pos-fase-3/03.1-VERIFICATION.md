## Comandos candidatos para o gate final

Os scripts podem ser ajustados em P08, mas o gate deve cobrir no mínimo:

```powershell
corepack pnpm install --frozen-lockfile
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
npx prisma validate
docker compose -f infra/docker-compose.dev.yml config --quiet
```

Também são obrigatórios: migration-from-zero em PostgreSQL efêmero; Docker build/start do backend; integração isolada; testes negativos de tenant; storage; aprovação; auth; webhook/limites; PDF real. Nenhum lint com `--fix` deve ser usado como verificação.

## Regras de exceção

- Falha, timeout ou teste não executado não é PASS.
- Mock não substitui integração quando o risco está no renderer, banco, storage, fila ou HTTP.
- Exceção requer motivo, owner, prazo e `HUMAN_APPROVAL` no arquivo de verification.
- Nenhuma exceção pode aceitar vazamento cross-tenant, objeto privado público, webhook sem autenticação ou cobrança real indevida.
