## T10 — policy privada aplicada

### Antes (capturado para rollback)

```json
{
  "orcivo-pdfs": "{\"Version\":\"2012-10-17\",\"Statement\":[{\"Effect\":\"Allow\",\"Principal\":{\"AWS\":[\"*\"]},\"Action\":[\"s3:GetObject\"],\"Resource\":[\"arn:aws:s3:::orcivo-pdfs/*\"]}]}",
  "orcivo-photos": "{\"Version\":\"2012-10-17\",\"Statement\":[{\"Effect\":\"Allow\",\"Principal\":{\"AWS\":[\"*\"]},\"Action\":[\"s3:GetObject\"],\"Resource\":[\"arn:aws:s3:::orcivo-photos/*\"]}]}"
}
```

Confirma o achado do inventário T01: os dois buckets ainda carregavam a
policy pública legada (`Principal: "*"`) porque o backend dev não havia sido
reiniciado desde o código do T03. Objetos existentes antes da mudança:
`orcivo-pdfs` = 2, `orcivo-photos` = 6.

### Ação

Aplicada exatamente a mesma operação que `StorageService.onModuleInit`
executa (`setBucketPolicy(bucket, '')` — limpa a policy, sem tocar objeto),
contra os dois buckets do MinIO dev. Nenhum outro bucket foi tocado (o
inventário confirmou que só existem `orcivo-pdfs`/`orcivo-photos` no MinIO
dev).

### Depois (verificado)

| Bucket | policy | objetos | GET anônimo | GET assinado | GET assinatura adulterada |
|---|---|---|---|---|---|
| `orcivo-pdfs` | `NoSuchBucketPolicy` (privado) | 2 (preservados) | 403 | 200 | 403 |
| `orcivo-photos` | `NoSuchBucketPolicy` (privado) | 6 (preservados) | 403 | 200 | 403 |

Nenhuma reescrita destrutiva de objeto — só a policy do bucket mudou.
`extractKey` continua aceitando URL legada completa para as linhas do banco
que ainda guardam a URL pública antiga (nenhuma migration necessária, já
implementado em T02/T07).

### Rollback

Para reverter (não deveria ser necessário — verificação acima passou):

```js
const { Client } = require('minio');
const c = new Client({ endPoint: 'localhost', port: 9000, useSSL: false, accessKey: 'minioadmin', secretKey: 'minioadmin' });
await c.setBucketPolicy('orcivo-pdfs', '{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"AWS":["*"]},"Action":["s3:GetObject"],"Resource":["arn:aws:s3:::orcivo-pdfs/*"]}]}');
await c.setBucketPolicy('orcivo-photos', '{"Version":"2012-10-17","Statement":[{"Effect":"Allow","Principal":{"AWS":["*"]},"Action":["s3:GetObject"],"Resource":["arn:aws:s3:::orcivo-photos/*"]}]}');
```

Não é a ação recomendada (reabriria acesso público), documentada apenas como
procedimento de emergência caso a verificação tivesse falhado. **Não
executada.**
